# BlockTask — decentralized TODO list

Индивидуальный учебный проект по курсу «Основы технологии блокчейн».

## Возможности
- Подключение кошелька через MetaMask в интерфейсе Scaffold-ETH-2.
- Добавление задач в личный список пользователя.
- Хранение задач в смарт-контракте Solidity.
- Переключение статуса задачи между активной и выполненной.
- События блокчейна при добавлении задачи и изменении её статуса.
- Проверка пустого описания и ограничения длины до 200 байт.

## Структура
- `packages/hardhat/contracts/TaskManager.sol` — смарт-контракт.
- `packages/hardhat/test/TaskManager.ts` — автоматические тесты контракта.
- `packages/hardhat/scripts/deploy.ts` — скрипт развёртывания.
- `packages/hardhat/hardhat.config.ts` — конфигурация Hardhat.
- `packages/nextjs/app/blocktask/page.tsx` — страница приложения для Scaffold-ETH-2.

## Запуск
Этот репозиторий содержит файлы проекта для добавления в установленный Scaffold-ETH-2.

1. Создайте проект по официальной инструкции Scaffold-ETH-2.
2. Скопируйте папки `packages/hardhat` и файл `packages/nextjs/app/blocktask/page.tsx` в соответствующие места проекта.
3. Установите зависимости Hardhat и выполните `yarn hardhat compile`.
4. Запустите тесты командой `yarn hardhat test`.
5. Запустите локальную сеть командой `yarn chain`, затем разверните контракт командой `yarn deploy`.
6. Добавьте `TaskManager` в конфигурацию контрактов Scaffold-ETH-2, используя созданный deployment artifact и адрес.
7. Запустите frontend командой `yarn start`, откройте страницу `/blocktask` и подключите MetaMask к локальной сети (chain ID 31337).

## Статус
Исходный код и тесты добавлены в репозиторий. Перед сдачей необходимо самостоятельно выполнить сборку и тесты в окружении Scaffold-ETH-2, развернуть контракт и сделать реальные скриншоты работающего приложения. Не следует считать тесты пройденными до фактического запуска.
