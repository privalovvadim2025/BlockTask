# BlockTask

Небольшой учебный проект - список задач с использованием блокчейна Ethereum.

## Что умеет приложение

- Добавлять новые задачи.
- Показывать список задач пользователя.
- Отмечать задачу как выполненную и возвращать её обратно.
- Хранить задачи в смарт-контракте.
- Разделять списки по адресам кошельков.

Для работы с кошельком используется MetaMask.

## Используемые технологии

- Solidity - смарт-контракт.
- Hardhat - компиляция, тестирование и развёртывание контракта.
- TypeScript - тесты и скрипт развёртывания.
- React / Next.js - страница приложения.
- Scaffold-ETH-2 - компоненты и хуки для взаимодействия с контрактом.

## Файлы проекта

- `packages/hardhat/contracts/TaskManager.sol` - контракт для работы с задачами.
- `packages/hardhat/test/TaskManager.ts` - тесты контракта.
- `packages/hardhat/scripts/deploy.ts` - скрипт развёртывания.
- `packages/hardhat/hardhat.config.ts` - настройки Hardhat.
- `packages/nextjs/app/blocktask/page.tsx` - страница со списком задач.

## Как запустить

Frontend-страница рассчитана на проект Scaffold-ETH-2. Сначала нужно создать и настроить его по инструкции Scaffold-ETH-2, затем перенести файлы из этого репозитория в соответствующие папки.

Для проверки смарт-контракта:

1. Установить зависимости проекта.
2. Выполнить `yarn hardhat compile`.
3. Запустить тесты командой `yarn hardhat test`.

Для локального запуска в Scaffold-ETH-2 используется локальная сеть Hardhat. Её можно запустить командой `yarn chain`, после чего развернуть контракт через `yarn deploy`. Затем нужно добавить адрес и ABI контракта в конфигурацию приложения и запустить frontend командой `yarn start`.

После запуска открыть страницу `/blocktask` и подключить MetaMask к локальной сети (Chain ID: 31337).

## Примечание

В репозитории находятся исходные файлы контракта, тестов и страницы приложения. Сборка и тесты пока не запускались в этом окружении, поэтому перед демонстрацией проекта их нужно проверить локально.
