# BlockTask

**Децентрализованный список задач на Ethereum**

BlockTask - учебное DApp-приложение для создания личного списка задач. Данные хранятся в смарт-контракте, а пользователь работает со списком через веб-интерфейс и кошелёк MetaMask.

---

## Возможности

- добавление новой задачи;
- просмотр списка задач текущего адреса;
- отметка задачи как выполненной и возврат в активное состояние;
- отдельный список для каждого адреса кошелька;
- проверка текста задачи перед записью в блокчейн;
- события смарт-контракта при добавлении задачи и изменении её статуса.

## Как устроен проект

| Часть | Назначение |
| --- | --- |
| Solidity | Логика хранения и изменения задач |
| Hardhat | Компиляция, тестирование и развёртывание контракта |
| React / Next.js | Пользовательская страница BlockTask |
| Scaffold-ETH-2 | Основа frontend и взаимодействие с контрактом |
| MetaMask | Подключение кошелька и подтверждение транзакций |

## Запуск

Frontend подготовлен для интеграции в проект [Scaffold-ETH-2](https://github.com/scaffold-eth/scaffold-eth-2). Это не полный шаблон Scaffold-ETH-2: сначала необходимо развернуть сам Scaffold-ETH-2, затем перенести файлы из этого репозитория в соответствующие каталоги.

### 1. Смарт-контракт

В окружении Scaffold-ETH-2 установите зависимости и запустите локальную сеть:

```bash
yarn install
yarn chain
```

В другом терминале выполните компиляцию и тесты:

```bash
yarn hardhat compile
yarn hardhat test
```

### 2. Развёртывание

После запуска локальной сети разверните контракт:

```bash
yarn deploy
```

Затем добавьте адрес и ABI контракта в конфигурацию Scaffold-ETH-2, чтобы frontend мог обращаться к нему.

### 3. Интерфейс

Запустите frontend:

```bash
yarn start
```

Откройте страницу `/blocktask` и подключите MetaMask к локальной сети Hardhat (Chain ID: `31337`).

## Основные файлы

- **TaskManager.sol** - структура задачи, функции чтения и записи, проверки и события.
- **TaskManager.ts** - unit-тесты смарт-контракта.
- **deploy.ts** - скрипт развёртывания.
- **page.tsx** - страница со списком задач.

## Состояние проекта

В репозитории размещены исходные файлы контракта, тестов и страницы приложения. Перед демонстрацией необходимо выполнить команды компиляции и тестирования в настроенном окружении Scaffold-ETH-2, развернуть контракт и проверить взаимодействие с MetaMask.
