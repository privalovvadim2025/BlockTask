# BlockTask

Небольшое децентрализованное приложение для ведения списка задач. Данные о задачах хранит смарт-контракт в сети Ethereum-совместимого блокчейна.

## Что умеет приложение

- Показывает задачи, связанные с подключённым адресом кошелька.
- Добавляет новую задачу.
- Позволяет отметить задачу выполненной или вернуть её в активный список.
- Показывает общее количество задач и количество выполненных.
- Проверяет текст задачи: пустое описание и текст длиннее 200 байт не принимаются.
- Создаёт события `TaskCreated` и `TaskStatusChanged` при изменении списка.

## Используемые технологии

- Solidity - смарт-контракт `TaskManager`.
- Hardhat - компиляция, развёртывание и тестирование контракта.
- TypeScript - скрипты и frontend.
- Scaffold-ETH-2 - основа для страницы приложения и работы с контрактом.
- MetaMask - подключение кошелька и подтверждение транзакций.

## Запуск

Файлы frontend и Hardhat подготовлены для использования внутри проекта Scaffold-ETH-2. Сначала нужно создать или скачать проект Scaffold-ETH-2, затем перенести в него файлы из этого репозитория, сохранив указанную структуру.

1. Установить зависимости проекта Scaffold-ETH-2.
2. Скопировать `packages/hardhat` и страницу `packages/nextjs/app/blocktask` в соответствующие каталоги Scaffold-ETH-2.
3. Перейти в Hardhat-пакет и выполнить компиляцию:

   ```bash
   yarn hardhat compile
   ```

4. Запустить тесты:

   ```bash
   yarn hardhat test
   ```

5. В отдельных терминалах запустить локальную сеть и frontend, а затем развернуть контракт:

   ```bash
   yarn chain
   yarn deploy
   yarn start
   ```

   Команду `yarn deploy` нужно выполнить после запуска локальной сети.

6. Добавить развернутый `TaskManager` в конфигурацию контрактов frontend, используя адрес и ABI из результата развёртывания.
7. Открыть страницу `/blocktask`, подключить MetaMask к локальной сети разработки (обычно chain ID `31337`) и проверить добавление и изменение статуса задач.

## Проверки

В наборе тестов предусмотрены сценарии добавления задачи, генерации события, отклонения пустого текста, изменения статуса и разделения задач по адресам.

Перед сдачей нужно самостоятельно запустить `yarn hardhat compile` и `yarn hardhat test` в настроенной среде. До такого запуска нельзя считать тесты подтверждённо пройденными. Аналогично, для проверки frontend необходимо развернуть контракт и указать его адрес в конфигурации Scaffold-ETH-2.
